# Одна такая — вязаные вещи ручной работы

Статичный сайт, открывается с телефона и компьютера: https://s1mpleton123451-ai.github.io/vyazanie-site/

## Где что менять
Вещи, цены, статусы («в наличии», «под заказ», «продано»), название, Telegram, сроки, доставка, оплата и отзывы правятся в админке:
https://s1mpleton123451-ai.github.io/vyazanie-site/admin/ (вход по токену GitHub). Данные лежат в `content/site.json`.
После сохранения GitHub Pages сам обновляет сайт, изменения видны через 1–2 минуты. Список вещей без JavaScript и разметку для поисковиков обновляет `python3 tools/make_noscript.py`.

- Фото с телефона админка сама уменьшает и сохраняет в webp, в папку `img/`.
- В коде (`index.html`) остались только разделы каталога, виды вещей и цвета пряжи для «Своего заказа».
- Свой домен: купить домен, настроить DNS (инструкция внутри файла), потом `python3 tools/set_domain.py домен.ru`.
- Админка: Sveltia CMS 0.273.1, лежит в `admin/` целиком, внешние CDN не нужны.

Цены, сроки, доставка, материалы и размеры в макете придуманы, их нужно заменить настоящими.

Шрифты (Cormorant Garamond и Onest, лицензия SIL OFL) лежат в `fonts/`, с Google ничего не грузится.
